# /founder-intake

Read `agents/intake.md` and `playbooks/founder-intake.md` first.

Gather one question at a time:
1. founder name and domain
2. topics the founder should be known for
3. current business goal
4. existing proof assets or public materials

Produce:
- `founders/<founder-id>/profile.md`
- `founders/<founder-id>/prompts.json`
