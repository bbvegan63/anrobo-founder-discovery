# /external-signal-loop

Read `agents/external-signals.md` and `playbooks/external-signal-loop.md` first.

Gather one question at a time:
1. founder profile
2. source asset or linked page
3. channel and signal type
4. whether this is a distribution event or a response event

Produce:
- `founders/<founder-id>/external-signals.md`
- `founders/<founder-id>/evidence/YYYY-MM-DD-external-signals.json` when structured logging is useful
