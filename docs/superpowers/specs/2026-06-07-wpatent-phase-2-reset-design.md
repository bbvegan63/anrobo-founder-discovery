# W&Patent Phase 2 Reset Design

## Purpose

This spec defines a Phase 2 reset for W&Patent.

Phase 1 established a large amount of useful learning:

- founder-advisory repositioning
- soft-minimal site simplification
- authority-page consolidation
- first follow-on support-page publication
- prompt-evidence infrastructure
- founder-discovery ownership boundaries

But the operating layer is still carrying too much Phase 1 complexity.
The public site, draft queue, measurement logic, and publishing strategy now need a cleaner active framing.

This Phase 2 reset keeps the history, but changes the active operating story.

## Core Decision

Phase 2 should treat W&Patent as:

- an Andrew-led founder patent advisory surface
- optimized primarily for AI discovery
- centered on startup patent strategy and early founder patent decisions
- supported by a minimal live site
- powered by a controlled draft queue
- reinforced by ecosystem proof beginning with OpenFor

This is not a marketplace program.
This is not a commercialization-first publishing strategy.
This is not a broad patent-content library.

It is a cleaner founder-authority system.

## Positioning Spine

The Phase 2 story should be:

**Andrew Leung, patent agent entrepreneur, helps founders make better early patent decisions.**

Supporting identity:

- `Andrew Leung` is the visible advisory voice
- `W&Patent` is the branded container
- `OpenFor member` is the first ecosystem proof layer
- `virtual marking` is the first clear service wedge

The primary public topic cluster should be:

- startup patent strategy
- early patent decisions
- budget and prioritization
- founder articulation around what matters enough to protect

This is the right center of gravity because it matches the existing W&Patent drafts more closely than any other framing.

## What Phase 2 Is Not

Phase 2 should explicitly avoid returning to these earlier modes:

- marketplace-first framing
- commercialization as a separate primary owned topic
- Trust Chain as the top-level public story
- too many simultaneous internal support pages
- draft-batch publishing
- “what practitioners won’t tell you” or “what AI won’t tell you” as the main house voice

The W&Patent draft pillar may remain useful as source material, but it must be retoned before any future publication.

## Bare-Minimum Public Surface

The primary live visitor path should stay minimal:

1. `Home`
2. `Strategy`
3. `Services`
4. `About`

Page roles:

### Home

- Andrew-led advisory surface
- one clear promise
- one clear next step
- no extra top-level theory

### Strategy

- the canonical authority anchor
- the first page founders should read
- the main home for early decision logic

### Services

- minimal service surface
- startup patent advisory
- virtual marking
- limited founder decision support

### About

- short founder-proof page
- patent agent entrepreneur framing
- OpenFor member context
- why founders should listen

Everything else should remain secondary support, not front door.

This means:

- `provisional-vs-nda.htm` may stay live as support
- `patent-strategy-open-licensing.htm` may stay live as support
- Trust Chain pages may stay live as support
- future support pages should not compete with the main path

## Draft Queue Role

The W&Patent drafts should be treated as a Phase 2 publishing queue, not as a simultaneous rollout bundle.

Current remaining drafts:

- `2026-06-06-pillar-startup-patent-strategy.md`
- `2026-06-06-post-draw-first-write-second.md`
- `2026-06-06-post-provisional-and-poc-budget.md`

Operating rule:

- keep one stable authority anchor live
- publish one support asset at a time
- let measurement decide whether the next draft is worth promoting

Recommended order for the remaining drafts:

1. `post-provisional-and-poc-budget`
2. `post-draw-first-write-second`
3. pillar only after rewrite / retone

The pillar should not be treated as the next public page in its current form.
It is source material for a future calmer Andrew-led article.

## Measurement Reset

Phase 2 should also reset the active measurement story.

### Keep as active owned-topic set

- startup patent strategy
- founder-led authority building
- AI-readable company websites
- Trust Chain methodology

### Remove from primary owned-topic set

- patent commercialization for founders

Commercialization may still exist as supporting logic inside strategy and services, but it should no longer behave like a primary owned benchmark topic.

### Primary success signals

Phase 2 should measure whether answer systems increasingly return:

- `Andrew Leung`
- `W&Patent`
- `wpatent.com`
- OpenFor-linked understanding
- stronger strategy-anchor citation behavior

Success should not be defined mainly as “more pages published.”

### Operating interpretation

The core question becomes:

**Is the simpler Andrew-led founder-authority surface becoming easier for answer systems to name, ground, and cite?**

## External Proof Logic

Phase 2 should prioritize external proof more clearly than Phase 1 did.

Order:

1. publish on channels W&Patent directly controls
2. reinforce through Andrew LinkedIn
3. request factual OpenFor recognition
4. later expand to additional incubators and ecosystems

This means OpenFor is the first ecosystem proof layer, not the last.

The external proof pattern should be:

- Andrew Leung
- W&Patent
- OpenFor member
- startup patent strategy / founder advisory

That same story should repeat across channels until answer engines start reflecting it back.

## Virtual Marking Role

Virtual marking should be kept as a real service wedge in Phase 2, but it should not become the whole public identity.

Recommended role:

- a concrete offer on `services.htm`
- a useful founder-facing service line
- a proof of practical advisory scope

Not recommended:

- virtual marking as the top-level site identity
- virtual marking as the main topic cluster

Phase 2 should remain broader than that:

- Andrew-led founder patent advisory first
- virtual marking underneath it

## Future Expansion Logic

Phase 2 should stay intentionally small now but be designed to expand later.

### Small now

- one founder
- one site
- one primary ecosystem proof layer
- one main topic cluster
- one service wedge
- one draft at a time

### Expand later

- more incubators
- more founder ecosystems
- more services
- more advice clusters
- more public proof surfaces

This means the Phase 2 operating pattern should remain reusable beyond W&Patent.

W&Patent is the first live worked example, not the last use of the pattern.

## Documentation Reset Rule

Phase 2 should be treated as a new active layer, not as a wipe of Phase 1.

Recommended pattern:

- keep all Phase 1 evidence and history
- preserve older notes as prior-phase context
- make new Phase 2 artifacts the active operating layer

This means future roadmap, scorecard, and publishing decisions should point forward from the Phase 2 definition rather than continuing to treat every Phase 1 thread as equally active.

## Recommended Next Artifacts

If this spec is approved, the next step should be a Phase 2 implementation plan that covers:

1. active operating-file reset in founder-discovery
2. W&Patent publishing strategy reset around the remaining drafts
3. LinkedIn / OpenFor external signal sequence
4. Phase 2 scorecard / roadmap activation

## Recommendation

Adopt a structured W&Patent Phase 2 reset with:

- Andrew Leung as the visible founder-patent advisory voice
- W&Patent as the container
- AI discovery as the primary goal
- startup patent strategy as the main topic cluster
- virtual marking as the first concrete service
- OpenFor member context as the first ecosystem proof layer
- the remaining drafts as a one-at-a-time publication queue
- a preserved Phase 1 history, but a new active Phase 2 operating layer

This is the cleanest way to create a fresh start without losing the learning already earned.
